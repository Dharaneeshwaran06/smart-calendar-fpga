# FPGA Smart Calendar

A simple FPGA-based Smart Calendar implemented using Verilog HDL.

## Features

* Date and time counting
* Clock divider
* Event scheduling
* 7-segment display
* FPGA hardware implementation

## Files

* `smart_calendar.v` – Main module
* `calendar.v` – Calendar logic
* `time_counter.v` – Time counter
* `clock_divider.v` – Clock divider
* `event_scheduler.v` – Event scheduling
* `display.v` – Display control
* `smart_calendar_tb.v` – Testbench
* `smart_calendar.xdc` – FPGA pin constraints

## Tools

* Verilog HDL
* Vivado
* FPGA

## Project

FPGA-based Smart Calendar with real-time date, time, display, and event scheduling.
